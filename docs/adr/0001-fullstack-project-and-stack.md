# Один репозиторий для backend и frontend

Приложение сначала предназначено для одного владельца и развивается как адаптивный веб с установкой PWA. По решению владельца backend и frontend находятся в одном проекте: это позволяет согласованно изменять API и интерфейс без разделения на отдельные репозитории и процессы выпуска.

Backend: Python, FastAPI, PostgreSQL и SQLAlchemy. Frontend: React, TypeScript, Vite, Vitest, `@tanstack/react-query`, MobX, Tailwind CSS, shadcn/ui и TanStack Router. Это выбранный владельцем стек; документ не утверждает, что проводилось сравнительное исследование всех библиотек. PostgreSQL хранит синхронизированные данные, а SQLAlchemy используется для доступа к ним.

Выбор одного репозитория не требует одного процесса приложения или конкретного способа развёртывания. Версии зависимостей, управление миграциями, схема API, размещение и CI будут определены при реализации. Разделение ответственности React Query и MobX зафиксировано в ADR-0005, применение FEOD на frontend — в ADR-0006.
