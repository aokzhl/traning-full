# PWA и ручной учёт кардио вместо фонового GPS

Первый клиент — адаптивное веб-приложение для компьютера и телефона с установкой PWA. Для кардио пользователь вручную вводит вид активности, длительность и необязательную дистанцию; непрерывная запись маршрута, GPS, пульс и интеграции с часами отложены.

Для записи маршрута с заблокированным экраном требуется надёжная работа в фоне, на которую веб-геолокация не даёт опираться. Поэтому MVP не обещает такое поведение; отдельное мобильное приложение или импорт результатов можно рассмотреть позже. Это ограничение согласовано в обсуждении, а не запрет на получение текущей геопозиции при открытом приложении.

Настройка «Не гасить экран во время тренировки» использует доступные возможности браузера. Она действует в открытом приложении с учётом ограничений браузера и ОС и не обеспечивает фоновое выполнение. Таймер должен восстанавливать корректный остаток времени после возвращения; звук при заблокированном экране не является гарантией MVP.

Источники: [W3C Geolocation](https://www.w3.org/TR/geolocation/), [W3C Screen Wake Lock](https://www.w3.org/TR/screen-wake-lock/).
