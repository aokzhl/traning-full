# Запись без сети с последовательным переходом между устройствами

Связь в зале может пропадать, поэтому уже доступную на устройстве тренировку можно записывать без интернета с последующей синхронизацией. В MVP активная тренировка редактируется на одном устройстве; переход на другое происходит после успешной синхронизации. Пользователь выбрал этот вариант вместо обязательного постоянного подключения и вместо одновременного редактирования с разрешением конфликтов.

Локально записанный результат и подтверждённый сервером результат должны различаться в интерфейсе. Неотправленные изменения переживают обычную перезагрузку приложения; ошибка сети не должна выглядеть как успешная синхронизация. Первичная загрузка на новом устройстве требует подключения. Автоматическую отправку нельзя обещать исключительно в фоне: повторная попытка должна быть доступна и при возвращении в приложение.

Это решение фиксирует поведение, а не готовый протокол синхронизации. Формат локального хранения, повторная отправка без дубликатов, порядок изменений и защита от устаревшей записи со второго устройства должны быть определены до реализации синхронизации. Политика конфликтов для одновременной офлайн-работы на разных устройствах не входит в MVP.
