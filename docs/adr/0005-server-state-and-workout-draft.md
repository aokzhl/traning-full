# Серверное состояние и локальный черновик имеют разных владельцев

Официальный `@tanstack/react-query` отвечает за серверные данные и запросы через React-хуки, MobX — за локальный черновик тренировки и состояние интерфейса. Владелец подтвердил это разделение вместо второго полного кеша серверных данных в MobX, который пришлось бы отдельно обновлять и согласовывать.

Черновик может начинаться с серверного снимка, но не должен безусловно перезаписываться при фоновом обновлении запроса: неотправленные результаты принадлежат локальному черновику. Отправка и подтверждение изменений связывают эти области; долговременное сохранение черновика и очередь синхронизации проектируются отдельно. Наличие MobX или кеша запросов само по себе не выполняет требования офлайн-записи.

По просьбе владельца исследованы `mobx-view-model` и `mobx-tanstack-query`; [результаты и ссылки на исходники](../research/2026-11-05-mobx-view-model-and-tanstack-query.md) записаны отдельно. После обсуждения владелец выбрал `@tanstack/react-query`; `mobx-tanstack-query` в MVP не включается. Это оставляет запросы в официальной React-интеграции и уменьшает объём связывания жизненных циклов React и MobX.

Выбор query-пакета не утверждает использование `mobx-view-model` и `mobx-view-model-react`: они остаются исследованными кандидатами для моделей экранов. Независимо от выбора этих библиотек, освобождение модели экрана не должно удалять черновик активной тренировки. Офлайн-хранилище и протокол синхронизации остаются отдельной частью проектирования.
